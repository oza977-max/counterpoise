## What was built (plain words)
1. When a person confirms a case, the record now says where every answer came from (typed, filled by a model and ticked, changed, or carried from an earlier record). It is written once, on that attempt's `graph_confirmed` (or on `verdict_corrected` for a correction). D1's register lines now show real cases.
2. In the submitter view, the register detail has "Correct this check". It reopens the case on the form with every answer restored, ticks and quotes kept; an answer carried from an earlier record needs its tick again. Back is refused; confirming writes a `verdict_corrected` with the new sources.
3. A correction writes the corrected description only when it differs from the one now in force, so putting the first text back is recorded.
