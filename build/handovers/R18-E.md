## What was built (plain words)
1. **One way through a pre-check.** The old card-review screen ("Check what we read from your description"), the code that built it, and the model code that fed it are gone. After E: describe, optionally have a model pre-fill, confirm each answer on the form, then the verdict.
2. **Older cases can be corrected.** A case saved before Round 18 has no record of where its answers came from and no stored graph. In the submitter view of the register, "Correct this check" now opens the form with the description kept, each recorded "Not sure" put back as that answer marked "from the earlier record" (it needs the person's own tick), and every other answer blank and marked "not carried over from the earlier version". A case that recorded no "Not sure" opens entirely blank and marked. Back is refused and no model is called.
3. **The About page** no longer names a model, calls it free, or promises the description never leaves the computer. It names the three places a description can go and says every pre-filled answer must be checked and ticked.
4. **No invented original.** The rebuilt "original" of an older case is mostly the form's strict defaults for answers that were never kept. Nothing is compared against it: a correction of an older case writes no `graph_corrected` records and no `corrections_count` (an absent count is never read as "no answers changed").
