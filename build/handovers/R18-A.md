## What was built (plain words)
The pre-check now starts with one description box and, beside it, a live checklist of the form's 13 topics that reads "mentioned" or "not mentioned" as the person types (a symbol and words, announced to screen readers). The first Next lists the topics not mentioned with one-click example sentences; the second Next carries on. A description that tries to set its own rating gets a warning on the description screen ("We don't follow that: the rating comes from your answers and the firm's rules."). Every case now goes through the guided form — the old model route and its card-review screen can no longer be reached. On the form, one honest sentence says the description wasn't read automatically. Back from the form (for a fresh case only) returns to the description with the text kept, and pressing Next with unchanged text goes straight back to the form without repeating the similar-cases screen or writing the duplicate decision twice. Drafts are version 4; any draft saved by an earlier build opens safely. The ten worked examples of the user guide now live in one data module with answers in the form's own words.
