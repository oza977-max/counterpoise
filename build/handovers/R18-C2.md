## What was built (plain words)

The reading is now on screen.

1. After the similar-cases check, a person with a valid model setting sees "Reading your description…". The screen also says where the description goes, and has a Skip button.
2. They then land on the form with some answers pre-filled. Each pre-filled answer shows the quote it came from, highlighted inside its own sentence, and has its own "Yes, this is right" tick. There is no tick-all.
3. Continue stays shut until every pre-filled answer is ticked or changed. A "Still to check" line names what is left.
4. Changing an answer counts as checking it.
5. If the person edits the description so a quote disappears, that answer says the quote is no longer in the description.
6. Going Back and Next without changing the text never calls the model again. Changing the text reads it again, and anything the person already ticked, changed or typed is kept.
7. With no model, after Skip, or after any failure, the form opens with one true sentence. That sentence never points at a button that isn't on screen. If earlier model answers are still on the form, it says so.
8. The confirmation screen says "N of M answers were filled in by a model and confirmed by you".
9. The answers travel as one object through every later step, including a failed check and its retry. The verdict is built only from confirmed form answers.
10. A typed run and a pre-filled-then-ticked run of the same answers give a byte-identical verdict.

## Deviations from Spec
