## Chunk Summary

Make the describe-first screen real and leave a product that works end to end with **no model**:
a first-time visitor types a description, sees a live "mentioned / not mentioned" checklist, gets
the one-press nudge, answers the guided form, and reaches a verdict. The old LLM route becomes
unreachable. The chunk also lays the shared types and helpers later chunks build on.

## Framework Reference

Run tests with `npm test` / `npm test -- <path>` **never bare `npx vitest`** (Node 26 shadows jsdom's localStorage; the script sets `NODE_OPTIONS=--no-experimental-webstorage`). Unicode property escapes need the `u` flag: `/(?<![\p{L}\p{N}])foo/u`. Code points: `[...s].length`. `sessionStorage` is cleared after each test by `src/test-setup.ts`; `localStorage` is not.
