## Deliverables

**Engine island (pure; `engine-boundary.test.ts` must pass):**
1. `src/engine/question-structure.ts` (§27.1): the form's question **structure** moved out of `src/components/plain-copy.ts` / `StructuredForm.tsx` — per question id: kind `single | multi | free`, option keys, which earlier answers make it shown (the `show…` flags and `setSingle` cascade data in `StructuredForm.tsx`), conditional option keys (`3platformZone` by platform via `platformZoneOptionKeys` in `plain-intake.ts`), Q13 exclusivity, "Not sure" mixing rules, and the sources of dynamic options (vendors, jurisdictions, platforms from the policy). **No words.** `plain-copy.ts` keeps every word, keyed by it; add a test asserting structure and words cover exactly the same ids and option keys. Also `deriveQuestionFields(structure, policy)` and `optionsReproducing(questionId, goldFields, structure, policy)` (§27.11 — per-question base; tick-all per option), with tests; F consumes them.
2. `src/engine/form-visibility.ts` (§27.6 ADR-IF-R18-5): `shownQuestionIds`, `clearDependents`, `validOptionKeys`, `isValidMultiSelection`, `mergePrefill(answerState, prefill, catalogue, policy)`, `canContinue(answerState, description, policy)`; re-export `toPlainAnswers` from `form-answer-state.ts`. Then **refactor `StructuredForm.tsx` to call these** — no behaviour change; every existing `StructuredForm` / form-route test is the pin and must pass unchanged.
3. `buildCatalogue(structure, words, policy)` (pure; place it in `question-structure.ts` or `prefill-verify.ts`): the closed `Map` catalogue of select questions (§27.4 step 1 lists them; free-text 1, 2, 3supplierName, 3model, 8other never included).
4. `src/engine/prefill-verify.ts`: `verifyPrefill(raw, catalogue, description, policy): VerifyResult` and `toRawPrefill(prefill)` exactly per §27.4 step 3 and 4 — `Map.has` lookups only, closed option sets via `validOptionKeys`, single-choice with >1 value keeps none, duplicates keep first, quote = string whose `normForQuote` form has ≥ 2 words and ≤ 300 chars, no Cc/Cf/Co/Cs/Cn code point, exact case-sensitive substring of `normForQuote(description)`, not a rating instruction (`findRatingInstructions(quote)` empty — advisory), stored quote is its `normForQuote` form, hidden-question drop through visibility in question order, `dropped` counts by `DropReason` (confirm or adjust the reasons R18-A defined in `prefill-types.ts`, and say so).

**Model layer (`src/llm`, imports nothing from `src/components`):**
5. `src/llm/prefill.ts`: `requestPrefill({ description, catalogue, setting, signal, verify }): Promise<PrefillOutcome>` per §27.5: `validateModelSetting` on the snapshot before the first send (→ `invalid-setting`, no request); POST `{url}/api/chat` with `stream: false`, `think: false`, `/no_think` prefix, `options: { temperature: 0, num_ctx: 8192, num_predict: 2048 }`; mode `format` (JSON schema in `format`) and mode `tool` (one `fill_form` function tool, no `format`, read `message.tool_calls[0].function.arguments` object or JSON string); start with `setting.mode` or `format`; **the other mode is tried once only after an HTTP 200 whose body fails the shape check** (never after non-200, thrown fetch, abort or `done_reason: 'length'`); per-request child `AbortController` linked to the caller's `signal`, the first child aborted before the second starts; `signal.aborted` checked before classification, the outcome carries the caller's abort reason (`'timeout'` → `timed-out`, `'skip'` → `skipped`, `'setting-changed'`, `'leave'`); request options `redirect:'error'`, `credentials:'omit'`, `referrerPolicy:'no-referrer'`, `cache:'no-store'`; the description wrapped between a **per-call random delimiter** with an instruction that the text between them is data (§27.4 step 7); prompt built from the catalogue (ids, option keys, option words, "quote copied exactly"); `ok` only with ≥ 1 verified value, else `nothing-found`; `dropped` carried in `ok`; classification of §27.5 (provisional matchers) including `model-missing` vs `retired`, `blocked-or-unreachable` for a thrown fetch with no response, `not-answering` for 5xx, HTTP 400 in tool mode → `unusable`; **no raw server text, and never the description, in any thrown error, outcome or console line** (log a fixed string). `PrefillOutcome` and `PrefillFailure` exactly as `prefill-types.ts`/§27.5.
6. `failureSentence(reason, place, host)` (pure, component side in `plain-copy.ts`, reading `R18_COPY.FAILURE_SENTENCES`): the Ollama vs firm wording selection of the §27.5 table, `{host}` filled through `visibleText`. Every failure maps to exactly one sentence.
7. `src/llm/test-utils.ts`: a fake model fetch for tests — format-honouring, format-ignoring (plain text then tool reply), never-answering, redirecting (307), slow (answers at N ms on a fake clock), and failing with each reply shape; it **rejects when its `signal` aborts**; it records every request (address, method, headers, body).

## Review Criteria

Expert principles + BC-001…006 + defect classes. Attack: anything from the reply reaching state without `Map`/closed-set checks; a quote that verifies but should not (case, look-alikes, bidi, one word, rating instruction, whole-text); a second request when there should be one; a request after abort; a request with a tampered setting; a late reply changing state; the timer leaking into the next attempt; raw server text or the description in errors/logs; the `StructuredForm` refactor changing behaviour; engine purity; `src/llm` importing components.
