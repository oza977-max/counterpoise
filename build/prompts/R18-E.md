## THE TEST-DELETION RULE (read twice)

E deletes code, and so it will delete or re-point tests. In R18-A a builder deleted tests that still guarded **live** behaviour, and a review had to restore about ten. For E:

- **May be deleted.** A test may be deleted **only** if every behaviour it asserts belongs to a retired symbol in the table.
- **Mixed tests.** If a test also asserts something that still exists (the verdict, the register, the audit trail, the engine, the form, the policy, honesty markers), **re-point it to the form route**. Do not delete it.
- **Retired test-case ids.** Each deleted test's TC id moves to a `## Superseded` row naming R18-GI-10, so trace-check reports it openly.
- **Report table.** List every deleted test file or `it` in a table in your report and in the handover: file › test name › the retired symbol it covered › why nothing live is lost. Reviewers will audit it line by line.
